# Evidence screenshots

Status: **EMPTY — no screenshots captured**.

Keep a small set of images that prove a specific operational finding after manual execution. Each image must have a nearby caption stating the case, source/view, visible event/time window, and what the image establishes. Link the underlying sanitized evidence where possible.

Remove personal identifiers, secrets, unrelated browser tabs, public infrastructure details, and sensitive metadata before publication. Do not fabricate dashboards or alerts. A screenshot of installed tools does not prove collection or detection. Follow the [evidence policy](../docs/evidence-handling.md).
