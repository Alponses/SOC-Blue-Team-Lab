# Capturas de evidencia

Este directorio reunirá unas pocas imágenes que ayuden a comprobar hallazgos concretos. **Avance:** todavía no se han tomado capturas del laboratorio.

Cada imagen indicará caso, fuente o vista, evento o intervalo visible y qué demuestra. Cuando exista, se enlazará también el registro revisado que respalda el hallazgo.

Antes de publicar se retirarán identificadores personales, secretos, pestañas ajenas al caso, detalles de infraestructura pública y metadatos sensibles. Una captura de una herramienta instalada no basta para demostrar recopilación o detección. El criterio de selección está en las [reglas de manejo de evidencias](../docs/evidence-handling.md).
