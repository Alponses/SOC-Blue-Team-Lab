# Informes periódicos SOC

**Estado: plantilla preparada; ningún informe operativo emitido. NO DATA — DEPLOYMENT PENDING.**

La [Weekly Honeypot Threat Report](templates/weekly-honeypot-threat-report.md) está diseñada para un responsable SOC: resume cobertura, comportamientos relevantes, investigaciones, decisiones y mejoras. Se completará únicamente con telemetría observada y consultas reproducibles.

Cada informe identificará origen, sensor/época, ventana UTC, uptime, lagunas y retraso de importación. Reconciliar eventos, intentos, sesiones y alertas con las [definiciones de paneles](../dashboards/README.md); separar pruebas del operador y reproducciones. No usar números de muestra ni ceros como sustituto de datos aún inexistentes.

Los originales y anexos detallados permanecen privados. Publicar solo una copia revisada bajo un nombre que indique su ventana y con enlaces a [evidencias sanitizadas](../datasets/sanitized-honeypot/README.md) e [incidentes](../incidents/README.md). Seguir las [reglas de publicación](../docs/evidence-handling.md). Un reporte sin sesiones destacables puede documentar ruido, limitaciones y mejoras sin inventar incidentes.
